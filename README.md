# 기억쑥쑥 낱말놀이

70대 어르신을 대상으로 한 한국어 낱말놀이 퀴즈 게임입니다. 낱말 뜻 찾기, 초성 맞히기, 속담 완성 문제를 통해 언어 기억력과 집중력을 즐겁게 연습할 수 있도록 구성했습니다.

## 주요 기능

- 큰 글씨와 큰 버튼으로 구성한 고령 친화적 화면
- 낱말 뜻 찾기, 초성 맞히기, 속담 완성 3가지 유형의 한국어 문제
- 정답 선택 후 친절한 해설 제공
- 힌트 보기 기능으로 부담 없이 반복 학습 가능
- 진행률과 점수 표시

## 실행 방법

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
